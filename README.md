# everyday crew

Hero section for Everyday Crew — a premium everyday sock brand made in NYC.

React + TypeScript + Tailwind CSS v4 + Framer Motion, built with Vite.

## Develop

```sh
npm install
npm run dev
```

`npm run build` type-checks and produces a production bundle; `npm run lint` runs ESLint.

## Notes

- The background video is a Pexels free-license clip referenced by URL in
